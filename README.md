# BalansCheck
PDF financial statements extraction and arithmetic validation

## MVP іске қосу

Жоба бумасындағы терминалда:

```powershell
py -m http.server 8000
```

Содан кейін браузерден http://localhost:8000 ашыңыз. Демо нәтижесін көру үшін
**Демомен көру** батырмасын басыңыз. PDF талдау үшін мәтін қабаты бар файлды
жүктеңіз; мәтінді қолмен енгізу не түзету үшін **Алынған мәтінді көру немесе
қолмен өңдеу** бөлімін пайдаланыңыз. Нәтижені JSON немесе CSV форматында
жүктеуге болады. Серверді тоқтату үшін терминалда `Ctrl+C` басыңыз.

Қолданыстағы эталон интерфейс пен PDF/демо талдауы `index.html` ішіндегі
скрипттер арқылы жұмыс істейді; PDF.js пен веб-қаріптер CDN арқылы жүктеледі.
PDF файл браузерде өңделеді. Сканерленген PDF үшін OCR қажет.

`js/validation.js`, `js/scale.js`, `js/export.js` нь тусдаа модуль
прототипүүд бөгөөд одоогийн эталон `index.html` тэдгээрийг ачаалахгүй.
